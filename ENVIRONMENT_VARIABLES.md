# Environment Variables and JWT Keys

In oreder for the app to work fine, You need to acquire all the necessary secret keys, publick keys and required values for env variables. Complete detail is given below:

| Name       | Description                                                     |
| ---------- | --------------------------------------------------------------- |
| SERVER_URL | Hosted server url, default is `localhost:3001`                  |
| NODE_ENV   | Default is `development`, switch to `production` for deployment |
| ...        | Figure out the rest vars yourself                               |
